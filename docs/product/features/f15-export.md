# F15. Export history

- Release: v0.1
- Status: Approved 2026-10-07

## What

Export the full history to analyse it elsewhere.

## Rules

- Full JSON + one CSV per module + a README describing every field
- Date range selectable
- Intimate log only when explicitly selected
- Generated on the device; works offline

## Acceptance criteria

- [x] The export can be analysed by an external AI tool without extra explanation
